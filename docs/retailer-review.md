# Initial retailer access investigation

Reviewed 18 October 2026 using public web retrieval and public search. These are point-in-time observations from this environment, not assertions about future availability. No product catalog was scraped and no live prices were imported. Robots permission alone is not treated as a reuse license.

| Source | Structure/access observations | Robots / terms / API review | Decision |
| --- | --- | --- | --- |
| [Naheed](https://www.naheed.pk/) | Homepage retrieval returned HTTP 403. Reliable HTML structure could not be inspected. | [robots.txt](https://www.naheed.pk/robots.txt) could not be retrieved through the web tool. [Terms](https://www.naheed.pk/terms-and-conditions) were available through public search and assert ownership of site content. No permitted public catalog feed was verified. | Unavailable. Do not retry with spoofed browsers or bypass challenges. Ask the retailer about a licensed feed; an affiliate program link alone does not authorize collection. |
| [Springs](https://springs.com.pk/) | Homepage redirects to [branch/location selection](https://springs.com.pk/select-branch). Prices depend on order mode/location. Public footer pages indicate a storefront, but the actual product data structure was not validated. | [robots.txt](https://springs.com.pk/robots.txt) and guessed `/policies/terms-of-service` could not be verified. Public FAQ links to terms but full applicable terms were not established. No approved public product feed was verified. | Unavailable. Do not manufacture a branch cookie or bypass location selection. Obtain an approved source and explicit delivery-area semantics. |
| [Al-Fatah](https://alfatah.pk/) | Public storefront accessible; Shopify-style product/collection routes visible. Location/store selection is present. | [robots.txt](https://alfatah.pk/robots.txt) was retrieved and permits public HTML paths while restricting transactional and some AJAX paths. [Published terms](https://alfatah.pk/pages/terms-conditions) restrict site materials to personal shopping/noncommercial use and restrict redistribution. No licensed comparison feed was verified. | Unavailable for this platform until reuse permission/feed terms are established. A generic offline JSON-LD parser is supplied, not a live integration. |

Al-Fatah's robots comments also advertise commerce discovery endpoints. They were not invoked, and their presence does not establish authorization for bulk price collection or republication. No hidden endpoints, private APIs, authentication, CAPTCHAs, geo-cookies, or browser automation were used.

The implementation keeps separate adapters and records every attempted manual run. Current adapters always reject live collection, including if environment and admin flags are enabled. Enabling a future source requires a reviewed code change plus configuration, not just a flag.

Before changing a decision, record the retailer contact/permission basis, reviewed URLs, new review date, permitted fields and reuse scope, rate limit, variant rules, currency representation, area rules, and fixture provenance. Re-check the applicable rules before scheduled collection. Candidate future retailers have not been investigated and have no adapters.
